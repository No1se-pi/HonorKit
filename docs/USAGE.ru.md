# Руководство HonorKit

HonorKit — графическое приложение для регистрации и удаления отпечатков на
сканере, который уже работает со штатной службой `fprintd`. Оно подходит для
FPC A900 с драйвером из этого репозитория и использует публичный API fprintd.
Окно и подсказки доступны на русском языке.

## Установка и запуск

На Kali для сборки нужны Rust ≥ 1.92, GTK ≥ 4.10, заголовки GTK и pkgconf.
Установите зависимости, если они отсутствуют:

```bash
sudo apt-get install --no-install-recommends make pkgconf libgtk-4-dev
```

Из корня репозитория выполните обычным пользователем:

```bash
make install-app
```

В меню приложений GNOME найдите **HonorKit** по имени или по слову «отпечатки».
У приложения значок отпечатка. Команда `honorkit` открывает то же окно из
терминала. Если оболочка ещё не видит `~/.local/bin`, запустите
`~/.local/bin/honorkit` или добавьте этот каталог в `PATH`.

Установка размещает бинарник в `~/.local/bin`, а запись меню в
`${XDG_DATA_HOME:-$HOME/.local/share}/applications`. Параметр `USER_PREFIX`
в Makefile позволяет выбрать другой префикс. Каталог `bin` внутри него должен
быть доступен через `PATH` графического сеанса.

## Регистрация нового пальца

1. Запустите HonorKit из своего графического сеанса. Вверху должны появиться
   статус «Сканер готов» и название устройства.
2. Выберите руку и палец в раскрывающемся списке, затем нажмите **Добавить**.
   Уже сохранённые пальцы исключены из списка выбора.
3. Подтвердите запрос GNOME, если потребуется системное разрешение.
4. Касайтесь сканера и полностью убирайте палец между шагами. Слегка меняйте
   угол каждого касания. Анимация, текст и счётчик сопровождают этапы, которые
   присылает `fprintd`. При отключённых анимациях остаются текст и цвета.
5. Дождитесь сообщения «Отпечаток сохранён». Он появится в списке.
   Кнопка **Отменить регистрацию** завершает текущую попытку и освобождает
   устройство. Сохранённые ранее отпечатки остаются доступны.

## Удаление сохранённого пальца

У нужной строки нажмите **Удалить**, проверьте выбранный палец в окне
подтверждения и нажмите **Удалить отпечаток**. Операция касается одной записи.
Если этот палец использовался для входа, выберите другой зарегистрированный
палец или пароль.

Если отпечатки были изменены в GNOME Settings или через консоль, обновите список
кнопкой со стрелкой в заголовке. Если GNOME сообщает, что сканер занят,
закройте другой инструмент управления отпечатками или завершите его текущую
операцию.

## Проверка и удаление приложения

Проверить сохранённые записи можно без GUI:

```bash
fprintd-list "$USER"
fprintd-verify -f right-index-finger
```

Последняя команда проверяет правый указательный палец, если он зарегистрирован.
Графическая анимация относится к регистрации в HonorKit. Интеграция на экране
входа и блокировки использует собственный интерфейс GNOME. Она настраивается
отдельно по [руководству драйвера](../fingerprint/INSTALL.md).

```bash
make uninstall-app
```

Эта команда удаляет приложение и запись меню. Шаблоны, fprintd, PAM и демон
жестов можно управлять отдельно по инструкциям [для сканера](../fingerprint/INSTALL.md)
и [для тачпада](../gesture/INSTALL.md).

## Анимация после разблокировки и настройки тачпада

Нажмите шестерёнку в заголовке HonorKit. Раздел «Анимация разблокировки»
позволяет отключить эффект, выбрать стиль и длительность. Кнопка
«Предпросмотр» показывает выбранный вариант, а «Сохранить анимацию»
применяет его для последующих разблокировок. При отключении анимаций
в GTK остаётся короткая статическая карточка.

После входа в GNOME запись автозапуска запускает фоновый наблюдатель.
Он ждёт успешной проверки отпечатка и фактической разблокировки текущего
сеанса. Эффект появляется на рабочем столе. Для текущего сеанса после
первой установки его можно запустить с помощью `honorkit --unlock-watch`.
`make uninstall-app` удаляет и запись автозапуска. Уже запущенный
наблюдатель завершится при выходе из сеанса. Настройки анимации хранятся
в `${XDG_CONFIG_HOME:-$HOME/.config}/honorkit/unlock.ini`.

Параметры жестов и отклика становятся доступны после
[установки системного модуля](../gesture/INSTALL.md#настройки-через-honorkit).
Настройки жестов общие для ноутбука. Силу отклика задаёт прошивка тачпада.
Обе операции подтверждаются паролем администратора в штатном окне Polkit.
